Quick guide

How to use this site

Use the steps below to check, rename, and organize your Penner FUEL and STATEMENT PDFs. Nothing is uploaded by this application.

  1. Get your statements. Download the required GST files from Penner ShareFile. You can use an extracted parent folder or keep the downloaded files in a ZIP.
  2. Select or drop the files. Drag and drop a GST folder or ZIP into the drop area, or use Choose GST parent folder / Choose a GST ZIP file. Matching PDFs must be directly inside an 8-digit dated folder such as 20260430.
  3. Wait for automatic analysis. The app reads the matching PDFs, detects their pay-period dates, automatically estimates the number of months, and checks for missing, incomplete, duplicate, or non-standard periods.
  4. Review the detected pay periods. A normal period should have one FUEL file and one STATEMENT file. Warnings show periods or files that need to be checked before you create the output.
  5. Review the rename preview. Check the detected period, unit number, and proposed filename. A typical output name looks like 2026-04_April_16-30_70161_FUEL.pdf.
  6. Create and download the output. Choose structured output, flat output, or both. Leave the CSV audit log selected if you want a record of the processing. Click Create output ZIP, then Download results ZIP.
What files are processed? Only filenames ending exactly in _FUEL.pdf or _STATEMENT.pdf. Files such as _FUELTAX.pdf, _REPAIRS.pdf, and _LEGS.pdf are ignored.
Expected pattern: normally 2 dated folders per month, with 1 FUEL and 1 STATEMENT PDF in each folder (4 matching PDFs per month).
